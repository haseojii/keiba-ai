# PR Summary: #5

- PR: https://github.com/haseojii/keiba-ai/pull/5
- Title: 実データ理解の整理と初期target・特徴量方針の明文化
- Base/Head: `master` <- `codex/real-data-understanding`

## What Changed
- `docs/data_notes.md` を実データ前提で具体化した。
  - 行単位仮説
  - target候補
  - リーク候補
  - 初期特徴量候補
- 初回 real-data baseline の推奨targetを `着順 <= 3` として明記した。
- `scripts/inspect_data.py` を `low_memory=False` に更新した。
- 実データ理解ステップのログを追加した。
  - `logs/experiments/2026-03-08_real_data_understanding_v1.md`

## Why Changed
- モデル構築前に、データ理解とリーク回避方針を明確化するため。
- 初回の real-data baseline を安全かつ小さく始めるため。

## Important Design Decisions
- まだ断定できない点は「仮説」として明記する。
- 初回targetは `win` ではなく `top-3` を推奨し、学習安定性を優先する。
- 特徴量は少数のレース前情報に限定し、段階的に増やす。

## Lessons Learned
- 実データ導入時は、モデル実装より先に列理解と除外方針が必要。
- リーク候補を先に書き出すだけで、次PRの実装ミスを減らせる。

## Likely Next Steps
1. `features/` に最小の実データ前処理（型変換・欠損処理）を追加する。
2. `top-3 target` で最初の real-data baseline を実行する。
3. ログで比較しながら、特徴量を1つずつ段階追加する。
